TRAVEL COMMAND CENTRE — TOKYO 4-YEAR FULL SIMULATION S25

This is a dedicated simulation build, not the working S24 baseline and not MASTER.

Simulation date: 20/02/2030
Current stay: Tokyo, Japan

The build is deliberately heavily populated with four years of completed travel, expenses, reservations, calendar items, Journey History, Vault records, accounts, permanent checklists and destination checklists. Future itinerary is already entered for Kyoto, Osaka, Seoul and Bangkok Return.

INTENTIONAL ALERT CASES
Kyoto, Seoul and Bangkok Return have no Destination Budget. This is deliberate so Kym can see how Home Alerts and App Health identify missing budgets. Osaka has a budget set, providing a side-by-side normal future-stay example.

The simulation uses its own local-storage key, so it does not use the normal production-state key.
